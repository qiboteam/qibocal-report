# User Guide: Desktop Launcher

**Qibocal** is the desktop application that does what a web page is not allowed to do: reach the machine it runs on. It carries the name of the command line it drives — there is no other Qibocal application — and is called *the launcher* in this guide wherever the two have to be told apart. It starts report servers and notebook sessions, here or on another machine over SSH, edits the configuration shared with the command line, re-issues administrator invitations — and embeds the very same dashboard that is deployed on the web, so there is no context switch between launching an instance and browsing its reports.
