# ✉️ Invitation System & Team Onboarding

The Qibocamp Server uses a tokenized invitation system for self-registration. New users cannot arbitrarily sign up for an auth-protected instance unless they possess a valid invitation token generated by a server Administrator.

---

## 🎟️ How Invitations Work

An invitation token is a cryptographically secure random string associated with:
1. **Target Role**: The role (`Viewer`, `Editor`, or `Admin`) immediately assigned to the user upon registration.
2. **Expiration Policy**: The timestamp after which the invitation is no longer valid.
3. **Usage Limit**: Whether the token is single-use (default) or can be used multiple times.

When an invited user completes registration:
- Their account is created with the exact role defined in the token.
- They are immediately logged in with an authenticated JWT session.
- The token's usage count is incremented (or deleted if single-use).

---

## 🛠️ Generating an Invitation

Administrators can create invitations directly from the **Server Administration** page (`#/server-admin`):

1. Navigate to **Server Administration** via the sidebar or Server Management top bar.
2. Under **Generate Invitation Token**, configure the parameters:
   - **Role**: Choose `Viewer (Read-only)`, `Editor (Modify reports)`, or `Admin (Full privileges)`.
   - **Expiration**:
     - `1 Hour` (temporary quick access)
     - `24 Hours` (1 day, standard onboarding)
     - `7 Days` (1 week)
     - `30 Days` (1 month)
     - `Never expires` (permanent link for laboratory dashboards)
   - **Max Uses**: Enter `1` for a single team member, or enter a higher number (or leave empty for unlimited).
3. Click **Create Invite**.
4. The newly generated link is displayed with a **Copy Link** button.

---

## 🔗 The Invitation Link Format

The server is headless, so the link opens the deployed dashboard and tells it the server's address:
```text
https://qibo.science/qibocamp/#/invite?token=<token>&server=<server-url>
```
For example:
```text
https://qibo.science/qibocamp/#/invite?token=inv_6e84d72b94f0...&server=http%3A%2F%2F192.168.1.100%3A8000
```
A password-reset link has the same form, with `reset_token=` in place of `token=`. `QIBOCAMP_DASHBOARD_URL`, set where the link is made, points it at another deployment of the dashboard.

## 👥 Onboarding Workflows for Team Members

New users can join using either of two frictionless methods:

### Method 1: Direct Link in Browser
1. The user opens the invitation link in their web browser.
2. The **Join Qibocamp Server** self-registration view is presented:
   - Displays the server URL and the role granted by the invitation.
   - Shows the expiration status of the token.
3. The user inputs their chosen **Username** and **Password**.
4. Clicking **Complete Registration** creates the account and directs the user to the active calibration dashboard.

### Method 2: Paste Box in Server Management
Users who already have the dashboard open or manage multiple lab servers can paste the invite link directly:

1. Open the **Server Management** page (`#/servers`).
2. Paste the invite URL into the top search/connect box:
   ```text
   https://qibo.science/qibocamp/#/invite?token=inv_6e84d72b...&server=http%3A%2F%2F192.168.1.100%3A8000
   ```
3. Press **Enter** or click **Connect**.
4. The client automatically:
   - Detects the remote server address and registers it in the local instance list.
   - Parses the token and displays the registration dialog with the token pre-filled.
   - Authenticates the user and opens the server once registered.

## 🚫 Revoking Active Invitations

To invalidate an invitation token before it expires or before its remaining uses are consumed:
1. Go to **Server Administration** (`#/server-admin`).
2. Scroll to the **Active Invitation Tokens** table.
3. Locate the token and click **Revoke**.
4. The token is immediately deleted and can no longer be used for registration.

---

## 🔑 Restoring Admin Access via CLI (`qibocamp report admin invite`)

If you deleted the server entry from your web client interface, lost your session token, or need to recover access from the server machine, you can regenerate an invitation link directly from the command line.

### Listing Existing Administrators

View the administrators registered in the server database:

```bash
qibocamp report admin list
```

### Regenerating the Invite Link

Run the `admin invite` command:

```bash
# Interactive selection (lists administrators and prompts for choice):
qibocamp report admin invite

# Non-interactive generation for a specific administrator:
qibocamp report admin invite <username>

# Shortcut alias:
qibocamp report invite <username>
```

### Reclaiming Access

Once the link is generated:
1. **Direct browser access**: Open the link (`https://qibo.science/qibocamp/#/invite?token=...&server=...`). The username will be pre-filled and designated for that administrator. Enter your password to update credentials and immediately log in.
2. **Server Management paste box**: In the dashboard's Server Management (`#/servers`), paste the entire invite link into the search bar. The client will automatically re-add the deleted server to your local list, prompt for credentials, and sign you in as administrator.
