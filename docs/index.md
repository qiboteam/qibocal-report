## 🌐 The Qibo Ecosystem

The **[Qibo](https://qibo.science)** framework is an open-source, modular full-stack quantum operating system designed for quantum simulation, quantum control, and quantum hardware calibration.

The ecosystem is partitioned into specialized, interoperable packages:

| Project            | Description                                                                                                    | Documentation                                                | Repository                                                            |
| :----------------- | :------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------- | :-------------------------------------------------------------------- |
| **Qibo**           | Core quantum computing API providing high-performance simulation backends, circuit definition, and algorithms. | [qibo.science/qibo](https://qibo.science/qibo/stable/)       | [qiboteam/qibo](https://github.com/qiboteam/qibo)                     |
| **Qibolab**        | Dedicated hardware abstraction and pulse-level instrument control layer for arbitrary quantum processors.      | [qibo.science/qibolab](https://qibo.science/qibolab/stable/) | [qiboteam/qibolab](https://github.com/qiboteam/qibolab)               |
| **Qibocal**        | Characterization, validation, and calibration protocols framework defining automated routines and runcards.    | [qibo.science/qibocal](https://qibo.science/qibocal/stable/) | [qiboteam/qibocal](https://github.com/qiboteam/qibocal)               |
| **Qibocal Report** | Modern web application and high-throughput server to explore, analyze, and manage Qibocal calibration reports. | [qibocal-report Docs](#/docs)                                | [qiboteam/qibocal-report](https://github.com/qiboteam/qibocal-report) |

## ⚛️ About Qibocal Report

`qibocal-report` provides an interactive, modern interface to inspect calibration data generated by **Qibocal**. It replaces static HTML generation with an interactive single-page application (SPA) backed by an asynchronous FastAPI server.

### Key Capabilities

- **Interactive Visualizations**: Zoom, pan, and inspect data points across calibration routines powered by Plotly.js.
- **Multi-Server Management**: Monitor and browse multiple remote Qibocal report servers across your lab network or HPC clusters from a single dashboard.
- **Smart Facets & Search**: Instant full-text search, author filtering, interactive timeline date histogram, and protocol frequency rankings.
- **Table & Card Views**: Switch between resizable, sortable tables and rich Inspire-HEP style summary cards.
- **On-the-Fly Downloads**: Download complete report archives, calibrated platform updates, initial platform snapshots, or individual protocol data folders as `.zip` archives.
- **Publication-Ready PDF Export**: Export clean reports directly from the browser with dedicated print media styles.
